# Markdown Files Viewer

**Live App:** [https://markdownfilesviewer.com/](https://markdownfilesviewer.com/)

A fast, **100% client-side** Markdown file viewer, live GitHub Flavored Markdown (GFM) editor, and multi-format document conversion suite that runs entirely inside your browser memory with zero server uploads.

## Key Features

- **Instant File Viewing & Editing**: Open `.md`, `.markdown`, `.txt`, `.docx`, `.pdf`, `.epub`, `.csv`, and `.html` files locally with drag-and-drop or the distraction-free [Editorial Reader](https://markdownfilesviewer.com/reader).
- **Complete GFM, MathML & Diagrams**: Supports tables, task checklists, callouts (`[!NOTE]`, `[!TIP]`, `[!WARNING]`), YAML frontmatter, native HTML5 MathML equations (`$...$`, `$$...$$`), and Mermaid diagrams.
- **Export from Markdown**:
  - [Markdown to PDF](https://markdownfilesviewer.com/md-to-pdf) — print-ready A4 PDF export
  - [Markdown to Word (.docx)](https://markdownfilesviewer.com/markdown-to-word)
  - [Markdown to HTML5](https://markdownfilesviewer.com/markdown-to-html)
  - [Markdown to LaTeX & Beamer](https://markdownfilesviewer.com/markdown-to-latex)
  - [Markdown to Excel / CSV](https://markdownfilesviewer.com/markdown-to-excel)
  - [Markdown to Slides](https://markdownfilesviewer.com/markdown-to-powerpoint) & [Social Card Images (PNG/SVG)](https://markdownfilesviewer.com/markdown-to-image)
- **Convert to Markdown**:
  - [PDF to Markdown](https://markdownfilesviewer.com/pdf-to-markdown), [Word (.docx) to Markdown](https://markdownfilesviewer.com/word-to-markdown), [EPUB to Markdown](https://markdownfilesviewer.com/epub-to-markdown)
  - [HTML to Markdown](https://markdownfilesviewer.com/html-to-markdown), [CSV to Markdown](https://markdownfilesviewer.com/csv-to-markdown), [Excel to Markdown](https://markdownfilesviewer.com/excel-to-markdown), [Rich Text Paste](https://markdownfilesviewer.com/rich-text-to-markdown)
- **Explore & AI Workflows**:
  - [Compare & Diff](https://markdownfilesviewer.com/compare), [Table Generator](https://markdownfilesviewer.com/tables), [Mermaid Diagram Builder](https://markdownfilesviewer.com/mermaid), [Mind Map Visualizer](https://markdownfilesviewer.com/mind-maps), [Markdown Templates](https://markdownfilesviewer.com/templates), [Slack mrkdwn Formatter](https://markdownfilesviewer.com/slack), [ChatGPT to LaTeX](https://markdownfilesviewer.com/chatgpt-markdown-to-latex), and [HTML to MD for LLMs](https://markdownfilesviewer.com/html-to-markdown-llms).
- **Private Zero-Server Share Links**: Compress and optionally encrypt documents in URL hash fragments (`#doc=` / `#enc=` using AES-256-GCM + PBKDF2-SHA256) so document text never hits server logs.
